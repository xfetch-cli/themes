<h2 id="before-opening-an-issue" align="center">Before Opening an Issue</h2>

<ul>
  <li>Confirm your xfetch version — theme format changed in v0.6.0 (no <code>icons</code> in themes).</li>
  <li>Test locally first: <code>xfetch theme set &lt;name&gt;</code> or load the file with <code>--config</code>.</li>
  <li>Include the theme name, the config snippet and the expected vs actual colors.</li>
  <li>For registry issues (missing theme, wrong source URL), name the <code>index.json</code> entry.</li>
</ul>

<h2 id="response-expectations" align="center">Response Expectations</h2>

<p>
  Maintainers triage reports based on impact and reproducibility. Clear, minimal reproductions are resolved faster.
